# Beryl M762 — Forge 1.12.2
Исходный проект под Minecraft Forge 1.12.2, Java 8 и ForgeGradle 2.3.

Сейчас включены регистрация предмета, начальная voxel-модель, текстура, локализации и GitHub Actions. Это стартовая основа, а не готовый мод: стрельба, прицел, отдача, боезапас и анимация перезарядки ещё не реализованы. Сборка пока не запускалась и не подтверждена. Модель стилизована для игры и не является технической копией реального оружия.
